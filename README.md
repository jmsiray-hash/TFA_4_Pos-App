# POS Application - TFA4: Sessions and Authentication

A database-backed Point of Sale (POS) web application built with **CodeIgniter 4**, featuring secure user authentication, password hashing, access control filters, and session management.

## Quick Running Links

Open `http://localhost:8080` in your browser. The local pages are:

* **Login Page:** http://localhost:8080/login
* **Home Page:** http://localhost:8080/
* **Customers Page:** http://localhost:8080/customers
* **Users Page:** http://localhost:8080/users

With Apache configured to serve the project from XAMPP:

* **Login Page:** http://localhost/TFA_4_Pos-App/public/login
* **Customers Page:** http://localhost/TFA_4_Pos-App/public/customers
* **Users Page:** http://localhost/TFA_4_Pos-App/public/users

## Run the application

From the repository directory, start the CodeIgniter development server:

```bash
php spark serve --host localhost --port 8080
```
